# Frame Sequence Directory

Place your extracted video frames into this directory.

### Supported File Naming:
The scroll sequence engine looks for frame files named numerically:
- `frame_0001.webp` (or `.png`, `.jpg`, `.jpeg`)
- `frame_0002.jpg`
- `001.jpg`, `002.jpg`, etc.

### Configuration
You can also load frames directly at runtime by dropping your `.zip` file into the web app using the bottom-right **"⚡ Upload Video Frames ZIP"** toolbar on the website!
