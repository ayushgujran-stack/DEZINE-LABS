# DEZINE LABS • Journey Media Folder

Place your personal journey videos and pictures in this folder (or `public/images/journey/`).

### Formats:
- Videos: `.mp4`, `.webm`, `.mov`
- Images: `.jpg`, `.png`, `.webp`

### Default 6 Cinematic Slots:
- Slot 1: `journey-01.mp4` / `journey-01.jpg`
- Slot 2: `journey-02.mp4` / `journey-02.jpg`
- Slot 3: `journey-03.mp4` / `journey-03.jpg`
- Slot 4: `journey-04.mp4` / `journey-04.jpg`
- Slot 5: `journey-05.mp4` / `journey-05.jpg`
- Slot 6: `journey-06.mp4` / `journey-06.jpg`
